# 消行音效 · B 版

`line-clear-meow-b.wav` 是用户试听后选定的 B 版，约 0.534 秒，44.1 kHz、单声道、16-bit PCM WAV。游戏每次消行播放一声；同时消除多行仍只播放一次。右上角音效开关控制全部声音，开启时播放一次猫叫作为试听。

来源：[Cat Meowing — qubodup](https://freesound.org/people/qubodup/sounds/813113/)，该作者整理自 tuberatanka 的 `cat meow II` 录音。

许可：[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。

处理：从公开高质量 MP3 试听版本解码，提高两个半音（速度约 1.122 倍），峰值约 -4.14 dBFS，4 ms 淡入、8 ms 淡出。游戏使用的 WAV 与用户选定的试听 B 文件完全相同。
